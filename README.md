## 使用术语

这些链接统称 Research Resources（研究资源）。GitHub 项目称 Repository／Repo（仓库）；整理多个链接的文档称 Resource List（资源清单）。只有具有参与者和持续交流的组织或群体适合称 Community（社区）。网站可称 Research Portal（研究门户），地图和测试集称 Benchmark（基准）。
